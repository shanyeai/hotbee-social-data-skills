# Synthetic Douyin report demo

This directory demonstrates the output contract of `hotbee-douyin-video-report` without calling HotBee or Douyin.

- `report.html` is a complete local report with interactive comment filters.
- `report-card.svg` is the compact shareable card.
- `sample-comments.json` and `sample-transcript.md` are synthetic inputs.
- `generate_demo.py` regenerates every demo artifact using the production report renderer.

All names, metrics, comments, URLs, and identifiers are fictional. Do not replace them with private or unredacted production data in a public pull request.
